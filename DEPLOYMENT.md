# Deployment Guide — Hitech AVL CRM

Full-stack production architecture: React frontend (Nginx) + FastAPI backend + Supabase PostgreSQL.

```
Internet → Coolify (Traefik) → frontend (Nginx, port 80 / mapped port)
                             → /api/* proxied to backend (port 8000, internal)
                               → Supabase PostgreSQL (Direct connection)
```

## Coolify Deployment Steps

1. **Create Project in Coolify:**
   - In your Coolify dashboard, create a new project/resource.
   - Select **Application** → **Docker Compose**.
   - Connect your GitHub repository (`anshuav2000-web/hitech-avl-crm`) and select the `main` branch.
2. **Configure Environment Variables:**
   - In Coolify, set the required environment variables:
     - `DATABASE_URL`: Your Supabase PostgreSQL Direct connection string (session mode, e.g. `postgresql://postgres.xxx:password@aws-0-ap-south-1.pooler.supabase.com:6543/postgres`).
     - `JWT_SECRET`: A secure random string (at least 32 characters).
     - `ADMIN_EMAIL`: Initial administrator email.
     - `ADMIN_PASSWORD`: Initial administrator password.
     - `FRONTEND_URL` / `PUBLIC_BASE_URL`: The public URL generated by Coolify.
3. **Deploy:**
   - Click **Deploy**. Coolify will build the Docker images for frontend and backend using `docker-compose.yml`.
   - The backend container automatically bootstraps and runs database migrations on startup (`pgbootstrap`).
4. **Verify Deployment:**
   - Open the Coolify-generated URL.
   - Test the health endpoint: `GET /health` (returns `{ "status": "ok", "database": "connected" }`).
   - Log in with your configured `ADMIN_EMAIL` and `ADMIN_PASSWORD`.
   - Verify CRM features, products, leads, and quotations.

## Production Stack Details

- **Frontend:** Built with React, served by Nginx 1.27 Alpine. Client-side routing falls back to `index.html`. `/api/` requests are seamlessly proxied to the backend container over the internal Docker network.
- **Backend:** FastAPI running on Python 3.12 with Uvicorn (`--workers 2`), communicating with Supabase PostgreSQL via `asyncpg`.
- **Database:** Supabase PostgreSQL (`DATABASE_URL`). No local database container or MongoDB dependency exists.
